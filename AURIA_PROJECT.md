# AURIA

Personal music player project for Android and Windows, based on
[Levyra](https://github.com/LUC4N3X/Levyra-deepsound).

## Planned features

- Preserve local music and online playback in a shared queue.
- Learn listening preferences from favorites, repeats and skips.
- Recommend and queue online tracks automatically after local songs.
- Support an offline intelligent radio mode based on local files.
- Build optional DJ transitions using BPM, key and crossfading.
